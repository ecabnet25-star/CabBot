# Web Support Added

You can now use the Social Media Bot from your web browser, locally and for free!

## How it works
- When you run the app, it starts a local web server (Flask) on your computer.
- Open your browser and go to: http://localhost:5000
- Use the web interface to compose, schedule, and post just like the desktop app.
- No cloud or paid hosting required. All data stays on your computer.

## How to use
1. Run the app as usual (python main.py or the packaged .exe).
2. Visit http://localhost:5000 in your browser.
3. Use the web UI to post or schedule to X, Reddit, Telegram, Instagram, and Facebook.

---

If you want to customize the web UI, edit `social_media_bot/templates/index.html`.
